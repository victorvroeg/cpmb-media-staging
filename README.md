# cpmb-media-staging

Temporary video staging for the Cedric Price Memory Bank
(github.com/victorvroeg/cedric-price-memory-bank), served over GitHub Pages
while the permanent streaming host is chosen. HLS renditions transcoded from
the 2014 master exports.

Disposable by design: when films move to the streaming host, the archive's
`video.hls` fields are re-pointed and this repository is deleted. Nothing
here is a master; masters live in cold storage (see the archive's
RESURRECT.md ownership register).
